# MAYA

MAYA is a personal AI agent manager designed to operate as a desktop AI assistant.

## Vision

MAYA will combine:

- Online AI models
- Multi-model routing
- Agent orchestration
- Persistent memory
- Tool execution
- Desktop automation
- Google integrations
- Workflow automation
- User-approved pattern learning
- A visual desktop dashboard
